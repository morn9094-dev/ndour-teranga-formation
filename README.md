# NDOUR TERANGA — Plateforme de formation

## Ce qui est inclus
- Accueil professionnel avec logo et photo du formateur
- 5 niveaux de formation
- Leçons avec explications, exemples et exercices
- Quiz avec correction et score
- Progression enregistrée dans le navigateur
- Espace étudiant
- Certificat imprimable / enregistrable en PDF
- PWA installable sur Android
- Aucun contenu vidéo

## Lancer
Ouvrir `index.html` dans un navigateur. Pour que le mode PWA/service worker fonctionne correctement, servir le dossier via un petit serveur local ou un hébergement HTTPS.

## Important pour une vraie plateforme en ligne
Cette version est fonctionnelle côté navigateur, mais les comptes étudiants réels, mots de passe, base de données, synchronisation multi-appareils et administration sécurisée nécessitent un backend + base de données + hébergement. Le projet est structuré pour cette prochaine étape.
